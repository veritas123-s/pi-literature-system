# 独立科学验收与单 Agent 基线

当前仓库提供评估合同、配对运行接口和来源核查器。四学科隐藏参考集、真实配对模型运行和独立人工评分尚未完成，因此目前没有科学验收分数。

四个固定案例定义在 `scripts/benchmark.ts`：重度哮喘生物制剂临床研究、甲状腺眼病 TSHR 与 IGF-1R 基础机制、溃疡性结肠炎单细胞巨噬细胞分析、IgG4 相关疾病 FAPI PET 分子影像。每个案例关注正面研究、阴性或竞争证据及研究设计边界。

## 执行与配对

先登记日期、模型配置哈希、工具清单和预算。`runBenchmarkPairs(adapter, config)` 向适配器传递相同模型、相同工具、相同预算和同一个案例；单 Agent 使用一个 researcher 会话贯穿检索、提取、综合和自查，四 Agent 使用四类独立会话。适配器应使用项目的 PiKernel、原文读取工具和相同检索连接器，禁止给其中一组额外工具或提示隐藏答案。配对运行按案例串行执行，使用独立目录和证据存储，不共享模型会话与上游产物。必须保存真实模型用量及任务输出。

运行接口只接收公开案例与执行设置；它不接收隐藏标签和人工评分表。当前尚无完成科学验收的模型适配器运行记录。也可将已经生成的两组 ResearchBundle 和执行设置写入评估输入，核验器负责比较合同、文件哈希及评分关联。

## 隐藏参考集和人工评审

由参考集整理人收集关键研究、重大阴性结果、竞争解释和撤稿信息，按研究而非论文去重。独立评分人必须不同于整理人。开发资料 DOI/PMID 列表与隐藏资料标识不得重叠。每项原始来源必须提供真实文件路径及 SHA-256，评分时重新读取校验。

参考集在运行前封存，标签和答案不交给 Agent。独立评分人填写未用于开发、未泄漏标签的声明；程序会验证字段、日期、身份和拆分标识，但历史上是否泄漏仍依赖独立评审者的真实声明，无法由一个 JSON 布尔值证明。

人工评分覆盖所有核心论断、每项证据的样本量及结果、所有范式，以及全部隐藏研究的报告表现。评分记录需要实际产物 ID、原文指纹、评分人和原文已检查状态。关键数字、单位、分母及不确定性需要独立复核。非核心论断的抽查范围在运行前确定并保持两组一致。

## 命令和输出

```powershell
node --import tsx scripts/benchmark.ts init work/benchmark/assessment.json
node --import tsx scripts/benchmark.ts evaluate work/benchmark/assessment.json work/benchmark/results
```

模板没有成绩。缺少评分人、来源哈希、隐藏拆分声明、配对运行、完整核心论断评分或源文件时，评估退出并输出 `not_evaluated`，不会计算分数。

有效评估按案例和组别输出关键研究召回率、引文支持准确率、字段准确率、重大反证处理和范式追溯结果，并记录样本量。目标仍为 90% 关键研究召回、95% 引文支持、95% 字段准确、无严重失真、重大反证得到处理及范式核心步骤有来源。未达到目标会如实标 `below_target`。

工程部分单列引用图、源文件指纹、真实用量和任务状态。工程检查通过不能替代科学指标，也不能当作期刊或领域专家批准。
